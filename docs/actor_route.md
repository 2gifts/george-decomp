# Numeric actor route consumers

Three complete functions reconstruct 908 bytes / 227 original instructions.
Their numeric names and partial actor/state views describe observed fields;
they do not establish original class names, allocation sizes or asset limits.
The approved source-free proposal contains all six genuine incoming JALs,
whole raw and assembly identities for their containing callers, complete
predecessor/following intervals and terminal JR31 delay instructions. The
queue routine excludes four zero alignment bytes.

| Entry | Bytes | Observed behavior |
| --- | ---: | --- |
| `001B7AB8` | 488 | Query the road, select direction after an adjusted virtual callback, publish the tag and obtain the road plane; retain its fallback dot product. |
| `001E2D88` | 320 | Refresh a tagged target, query both endpoints, publish separate tag snapshots and pass fresh values to the seven-register setup before queueing. |
| `001CC628` | 100 | Queue a marked object with the original count threshold, marker order and repeated global reloads. |

The actor routine captures its owner before the road query. On success it
captures the normal address before calling a one-argument virtual method
with the signed halfword receiver adjustment. Its normal XYZ loads occur
after the callback, so mutation at the retained address is visible. The
direction byte store precedes the full record-tag load and plane-helper
arguments. Failure retains integer and byte clearing, tag `FFFFFFFF`, normal
stores in X/Z/Y order, and the dot product using the numeric owner's fresh
direction fields.

The state routine uses the published tagged position resolver. Its XYZ
copy consists of sequential load/store pairs; shifted aliases therefore
retain their effects. It captures the target address before its two real
road queries. Either failed query writes the failure byte without fabricating
tag or vertex outputs. When both succeed, it captures the owner before the
tag stores, saves two tag snapshots, then reloads the second tag and finally
the first tag for the setup call. The snapshots and actual call arguments
can differ when the records alias the state. Queueing reloads the owner;
the flag halfword is loaded after queueing.

The queue's global byte count is checked before the object's existing marker.
A full queue returns zero even for a marked object. Otherwise an existing
marker returns one. A new marker is published before the fresh manager/count
used for insertion, and the final increment uses another fresh manager/count.
The threshold is observed behavior; it does not prove a general format or
allocation capacity. The source adds no capacity or pointer guard.

## Source reuse and supporting interfaces

Production uses the real road query and the previously reviewed goal plane
and tagged-position routines with existing partial layouts. The native runner
executes the selected source and real road/provider/bounds/registry/vector
source as separate translation units. It compiles unchanged Sun/newlib
`ceilf.c` and GNU `fp_bit.c` with their authentic selector defines and explicit
little-endian host bit ordering. Their existing notices and license files are
preserved. These reused helpers receive no new source or matching award.

MinGW's PE linker checks undefined references in unused COFF sections before
garbage collection. To keep these tests isolated, the runner byte-extracts
the **complete existing function source** for `001CAFE0` and `001CFBF8`, along
with their exact `ADJUST_THIS`, `ADDRESS`, `FIELD`, `lookup_road` and `record34`
dependencies, into two ignored native translation units. Every extracted
span preserves the published raw bytes and line endings. The proof records
each entire published source hash, extraction byte offset/size/hash,
generated translation-unit hash and actual compiler dependency closure.
This is reuse of the real reviewed helper function source; the complete
original goal translation units are not compiled in the native test.

In this actor packet, the getter `001BA610` and setup `0020D080` are
**supporting-only numeric entries**. The setup is independently recovered and
registered in [route setup](route_setup.md). The tracer executes both complete original bodies. Native tests
use explicit bounded observer bridges for their documented getter/store
behavior, together with controlled virtual frame/position and numeric
`00120B68` callbacks. They do not receive source or byte credit. Both genuine
target compilers demonstrate seven GPR argument lanes for the setup and no
COP1 instruction in that caller: GCC 3.2.3 emits JAL; GCC 2.9 emits a tail J.
Both also reproduce all 24 inspected layout words.

## Verification and limits

Nine actual whole-function links cover GCC 3.2.3, GCC 2.9 and GCC 2.9's
supported optional SAVE128 attribute. Each complete function is placed at
its original address, has no unresolved relocations, and requires no local
data mapping. None matches all original bytes. Ordinary source remains
reconstructed; no scheduling edits, cropped comparisons or assembly fallback
are used. The original compiler, syntax and stack choices remain unresolved.

The original tracer generates 96 synthetic fixtures: 75,120 executed
instructions, maximum 2,069 in one fixture. Every one of the 227 selected
instructions executes. Cases cover both individual endpoint failures,
missing roads, virtual and direct entity directions, negative/positive
receiver adjustments, mutation of normals and globals, referenced-target
types, shifted XYZ aliases, tag snapshots versus fresh setup arguments,
queue thresholds and the marker/count alias. The native test performs
2,182,795 warning-free checks, including every initialized word in the
10,241-word memory/global observation and controlled argument events.

Pointer relocation is limited to 44 explicitly typed synthetic cells plus
the manager global and known pointer argument/event positions. Both initial
and expected address-valued scalar words outside this ledger are rejected.
The ledger is an authored fixture view, not a game object-capacity claim.
Nine strict decoder guard methods pass; a fresh absent-original simulation
passes all six synthetic methods and intentionally skips the three methods
requiring the locally supplied game ELF. The original file is never moved
or deleted.

The observer covers initialized valid synthetic memory and separately rounded
finite normal/zero binary32 arithmetic. It does not prove EE FCR behavior,
special/subnormal arithmetic, timing, memory faults, exact stack placement,
arbitrary packed aliases or the complete indirect callback implementations.
Unused native closure hooks fail when reached. The selected void callers'
unused incoming/return floating lanes are not invented as arguments/results.
Only the queue's instruction-backed zero/one result is compared.

The author read all 227 selected original instructions, the complete connected
296-byte plane, 148-byte resolver, 8-byte getter and 272-byte setup originals,
the full 523 road-query originals and six supporting originals/active source

bounded ABI/result windows plus the entire selected 320-byte state caller;
