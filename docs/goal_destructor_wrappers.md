# Goal destructor forwarding wrappers

One complete ordinary C function forwards initialized storage and the unchanged
32-bit flags to the published base-destructor declaration. Seventeen complete
original 28-byte bodies share that function. Their constructor publications and
signed-adjustment dispatcher establish static callback paths; original classes,
prototypes, lifetime and runtime invocation remain unresolved.

The fixed GCC3.2.3 recipe naturally emits a complete 28-byte function whose
original-address links match all seventeen bodies. The whole 32-byte executable
section retains its separate four-byte zero alignment tail. GCC2.9 emits a
complete eight-byte tail-call alternative and remains a nonmatch. The initial
source and header, actual four target objects, all section/symbol/relocation
records, four ordered nine-file dependency queries and 38 complete selected and
ABI images are retained in the author evidence.

The original observer executes 544 cases at all seventeen actual addresses,
covering all 119 selected PCs and 3,808 instructions. These represent 32 unique
parameter sets without the address. Its helper is an explicitly controlled
effect seam: it observes pointer/flags forwarding, table publication before an
optional free event, complete initialized storage, saved registers and stack.
It does not execute or award the real destructor, allocator or heap.

The native harness runs those 32 parameters once and checks all 32 arena words
and callback events, for 1,056 checks. Only the two genuinely typed field0C
pointer cells use address-token translation. A single harness object is shared
by the unchanged production function and two complete changed-source controls:
skipping the call and flipping flag bit0. Both fail the actual event check at
fixture 0. Four native compiles and their individually pinned ordered dependency
closures, three whole images and raw streams are preserved.

The void storage-pointer/flags convention describes these independently compiled
memory effects. Measured GPR4/5, lower64 stack restoration and genuine callers
that overwrite the result do not prove original prototypes, upper128 behavior,
null lifetime or portable integration with every older source declaration.
The original observer records the helper's incidental GPR2 lane separately; the
native void result is never compared. Historical m2c drafts and their inferred
void(void) spelling remain unchanged and provide no original ABI proof.

The durable author packet is `build/goal_destructor_wrappers/frozen_inputs.json`.
Its contained replay relinks only the frozen target objects, checks the actual
original cases, reruns the unchanged guards and executes the three frozen native
images. It repeats no compiler, dependency query or native build. Complete
private evidence retains original words and tables; publication proposals contain
bounded geometry, hashes and evidence references. Final canonical acceptance and
matching receipts are separate from this author packet.
