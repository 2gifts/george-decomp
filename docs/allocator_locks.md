# Allocator lock hooks

The two independently reconstructed hooks at `0x003966E8` (96 bytes) and `0x00396748` (64 bytes) cover all 40 original instructions. Existing allocator call graphs bind them as `__malloc_lock` and `__malloc_unlock`. The conventional reent context is ignored. Supporting code and data references are binding evidence; no syscall implementation or global initializer is recovered or awarded here.

Acquire captures the signed 32-bit result of GetThreadId, then reads the owner. A different owner causes WaitSema with the freshly read semaphore. After waiting it publishes the captured thread, then loads and increments the fresh unsigned 32-bit nesting count. An equal owner skips waiting regardless of the count. Release subtracts one with wrapping arithmetic and stores the result before its zero test. Only zero loads the semaphore, publishes owner `-1`, and calls SignalSema. It does not query the current thread or enforce ownership. Wait/signal return values are discarded.
